# Simple Kanban

Frontend-only Kanban board built with React + TypeScript.

## Features

- Three columns: **To Do**, **Doing**, **Done**
- Rick and Morty characters loaded from the GraphQL API
- New items require a title and assigned character
- Drag items between columns
- Reorder items within the same column
- Delightful celebration animation when an item moves to **Done**

## Run locally

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```
